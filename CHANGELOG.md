# Changelog

## v1.0 – October 2026
First public release.
- Open a single WAD or a whole folder; browse the entries by category, search them, and extract selected entries or everything.
- Textures → PNG (and original DDS): DXT1, DXT5, cube maps, 8-bit, 32-bit.
- Models → `.glb` with the real game skeleton and skin weights. Rigid parts (armour, helmets, beards, eyes) are placed on their joints automatically. Tested on all 9 Kratos outfits and the bosses.
- Skeletons → JSON, game text → TXT, raw entries → BIN.
- Command-line mode: `--cli <WAD or folder> <output>`.
- Dark UI with YouTube / Patreon / Discord links.
